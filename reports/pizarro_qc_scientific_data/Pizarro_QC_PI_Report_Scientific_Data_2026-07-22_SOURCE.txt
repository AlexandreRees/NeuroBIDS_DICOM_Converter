\section{Executive summary}
%==============================================================================

An automated deep-learning quality-screening layer was applied to
\textbf{T1-weighted} structural MRI using the published
\textbf{Pizarro et al.\ (2023)} ONNX classifier.
Outputs are continuous screening metrics used to
\textbf{prioritize targeted manual visual inspection}.
They are \textbf{not} used as automatic exclusion decisions.

\begin{quote}
\textit{The Pizarro model was used as an automated structural MRI quality
screening tool. Model outputs were not used for exclusion decisions but rather
to prioritize images for targeted visual inspection. Quantitative MRI quality
assessment remains provided by MRIQC.}
\end{quote}

\begin{quote}
\textit{No image or subject was excluded based solely on the Pizarro model
output. Predictions were used exclusively to prioritize targeted manual visual
inspection.}
\end{quote}

\noindent\textbf{Bottom line for the PI:}
the T1w screening package is complete and reproducible.
Use the visual-review priority queues (high model-estimated artifact
probability; high model uncertainty) to triage manual QC.
Do \textbf{not} interpret priority counts as a dataset failure rate or as
pass/fail labels.

%==============================================================================
\section{What this report is (and is not)}
%==============================================================================

\begin{enumerate}[leftmargin=*]
  \item \textbf{Is:} automated QC screening to prioritize visual review of T1w.
  \item \textbf{Is not:} an exclusion classifier or final quality verdict.
  \item \textbf{Scope:} \texttt{*\_T1w.nii.gz} only.
        FLAIR, T2w, DWI, functional, fieldmaps, and all other modalities are
        excluded from analysis tables and figures.
  \item \textbf{Language:}
        ``model-estimated artifact probability'',
        ``subjects prioritized for visual review'',
        ``screening priority'',
        ``automated QC screening''.
\end{enumerate}

%==============================================================================
\section{Interpretation for the PI}
%==============================================================================

\begin{enumerate}[leftmargin=*]
  \item \textbf{Technical success.}
        Existing predictions cover 83 subjects / 385 T1w images with zero
        inference failures. This PDF uses those outputs; inference was not
        re-run.

  \item \textbf{Use as triage.}
        Start visual QC with the high-probability queue, then the
        high-uncertainty queue. Priority counts are screening aids only.

  \item \textbf{MRIQC remains primary.}
        Quantitative MRI quality assessment for the dataset remains provided by
        MRIQC. Pizarro is complementary automated screening.

  \item \textbf{No automatic exclusions.}
        No image or subject was excluded based solely on the Pizarro model
        output.
\end{enumerate}
