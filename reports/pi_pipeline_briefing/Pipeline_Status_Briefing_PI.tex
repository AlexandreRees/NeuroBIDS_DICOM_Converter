\section{Problème MRIQC --- ce qui s'est passé (factuel)}

\begin{itemize}
\item Échecs massifs sur la node \texttt{smoothness} (AFNI \texttt{3dFWHMx -acf}): modèle ACF ne fit pas $\Rightarrow$ pas de \texttt{3dFWHMx.1D} $\Rightarrow$ pas d'IQM JSON.
\item Un patch avait été ajouté, mais \textbf{il ne s'appliquait pas}: mauvais import (\texttt{afni.preprocess} au lieu de \texttt{afni.utils}).
\item Correction: forcer \texttt{acf=False} / \texttt{\_acf=False} (FWHM classique). Vérifié dans les logs: \texttt{FWHMx patched (nipype.interfaces.afni.utils.FWHMx)}.
\item Résultat: sessions 78\,\% $\rightarrow$ \textbf{95\,\%}; BOLD 91\,\% $\rightarrow$ \textbf{99\,\%}.
\item Reste: 6 sessions (2 T1w + 10 BOLD manquants). Relances automatiques en place.
\end{itemize}
