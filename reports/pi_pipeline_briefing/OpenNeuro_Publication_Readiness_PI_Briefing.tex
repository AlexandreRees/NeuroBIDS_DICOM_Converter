\section{What was built (technical walkthrough)}

\subsection{Inventory, mapping, and session confirmation}
\begin{itemize}
\item Source archive inventoried under \texttt{/project/def-amirs/raw\_original/} (Control, Glaucoma, Data\_ON, Data\_TON).
\item Series-level mapping frozen in \texttt{metadata/session\_mapping.csv} ($\sim$10\,026 MRI series) and session-level \texttt{metadata/mapping.csv}.
\item Session confirmation: \textbf{135 AUTO\_CONFIRMED} DICOM sessions + 6 auxiliary-only \texttt{NO\_DICOM\_FOUND}.
\item Manual overrides documented (e.g.\ SUBC044 patient\_id conflict) without disabling validation rules.
\end{itemize}

\begin{figure}[H]\centering
\includegraphics[width=0.92\textwidth]{Figure_mapping_PI.png}
\caption{Mapping / session confirmation summary for PI.}

\noindent\textbf{Documented gap (transparent):}
BIDS currently contains \textbf{124/135} AUTO\_CONFIRMED sessions.
The missing 11 are all non-Control \texttt{ses-02} visits (1 DataON, 1 DataTON, 9 Glaucoma).
Root cause: conversion arrays originally hard-coded \texttt{--session ses-01}; a follow-up
\texttt{ses-02} array converted Control successfully; the remaining 11 failed because
scratch lacked those cohort raw trees. Retry array \texttt{ses02\_r11} (job 66365527)
points at \texttt{/project/def-amirs/raw\_original} (verified present). Completing these
sessions is recommended before final OpenNeuro freeze but is not a QC failure of the
existing 124-session package.

\subsection{DICOM de-identification (derived copies only)}
\begin{itemize}
\item Applied on \textbf{derived} DICOM copies used for conversion --- the raw archive is never overwritten.
\item Policy oriented to DICOM PS3.15 Basic Application Level Confidentiality Profile (Annex E):
  documented custom subset (not a certified PS3.15 product claim).
\item Actions: clear PHI / free-text / site tags; pseudonymise PatientName/ID; remap UIDs;
  shift dates by participant-specific offsets (\texttt{metadata/deidentify\_date\_shifts.csv} ---
  \textbf{do not publish}); remove private tags except documented Siemens CSA needed for
  BIDS physics (SliceTiming, PE, bvals).
\item \textbf{Pixels unchanged} at this stage; acquisition parameters retained for science.
\end{itemize}

\item Tooling: \texttt{neuro\_pipeline} 2.1.0 + \texttt{dcm2niix}; BIDSVersion \textbf{1.9.0}; DatasetType \texttt{raw}.

\section{Quality control --- three complementary layers}

The QC strategy is deliberately multi-layer: screening (Pizarro), quantitative IQMs (MRIQC),
and diffusion technical validation (DWI QC). \textbf{None of these layers auto-excludes
subjects from the deposit.}

\begin{figure}[H]\centering
\includegraphics[width=\textwidth]{Figure_QC_three_layers_quality.png}
\caption{Single-figure QC summary for PI: Pizarro / MRIQC / DWI --- quality evidenced without automatic exclusions.}
\end{figure}

\subsection{Pizarro (T1w deep-learning screening)}
\begin{itemize}
\item Scope: all \textbf{356} T1w images; 0 load errors.
\item Outputs: artifact probability, confidence, uncertainty (Monte Carlo dropout).
\item Prioritisation thresholds used to queue visual review (e.g.\ high artifact probability /
  high uncertainty) --- \textbf{229} images prioritised; \textbf{0 automatic exclusions}.
\item Scientific Data framing: screening / prioritisation only; quantitative QC remains MRIQC.
\end{itemize}

\begin{figure}[H]\centering
\includegraphics[width=0.85\textwidth]{Figure_Pizarro_overview_PI.png}
\caption{Pizarro screening overview.}
\end{figure}

\subsection{MRIQC (anatomical + functional IQMs)}
\begin{itemize}
\item Software: MRIQC 24.0.2 with fault-tolerant wrapper in \texttt{neuro\_pipeline}.
\item Coverage (24 Jul 2026): subjects 84/84; sessions with all expected IQMs \textbf{120/124 (96.8\%)};
  T1w \textbf{354/356 (99.4\%)}; magnitude BOLD \textbf{1494/1496 (99.9\%)};
  combined \textbf{1848/1852 (99.8\%)}.
\item Quality headlines: median BOLD \texttt{fd\_mean} \textbf{0.176\,mm}; median tSNR \textbf{20.9}.
\item Engineering fix: mass failures traced to AFNI \texttt{3dFWHMx -acf}; corrected patch forces
  classic FWHM (\texttt{acf=False}) via correct nipype import --- session completeness rose
  from $\sim$78\% to 96.8\%.
\item Four remaining missing IQMs are \textbf{pathological / truncated acquisitions}
  (2 BOLD with 3--4 volumes; 2 abnormal T1w FOV/intensity) --- MRIQC fails correctly;
  do not block deposit.
\end{itemize}
