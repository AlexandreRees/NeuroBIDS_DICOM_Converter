## Role of the script

`main.m` is a **Psychtoolbox stimulus script** for eyes-open resting-state fMRI:
it presents a fixation cross on a black background in stereo mode and synchronizes
to the MRI scanner via a FORP / keyboard trigger channel.

## Scanner trigger

- **Present.** Uses PsychHID / `KbQueue` listening for key `t` (standard FORP TTL→keyboard mapping).
- `KbQueueWait` blocks until the first trigger; a loop then counts subsequent `t` keypresses.
