# NeuroPipeline DICOM Converter — Windows

Medical imaging DICOM → NIfTI desktop application for Windows.

## Requirements

- Windows 10/11
- ~200 MB free disk space for installation
- [dcm2niix](https://github.com/rordenlab/dcm2niix/releases) (`dcm2niix.exe`) on PATH, next to the app, or selected when prompted

**Python is not required** for end users.

## Installation

1. Download `NeuroPipeline_DICOM_Converter_Setup.exe`
2. Double-click the installer
3. Follow the wizard
4. Launch from the Desktop icon or Start Menu

## Quick use

1. Select DICOM folder
2. Select output folder
3. Click **START CONVERSION**
4. Open the HTML report

## Uninstall

Use **Apps & features** (Windows Settings) or the Start Menu uninstall entry.
