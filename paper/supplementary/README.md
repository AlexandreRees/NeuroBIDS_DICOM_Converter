# Supplementary material

Supplementary content is kept **separate** from the main manuscript body.

| File | Contents |
|------|----------|
| `supplementary_tables.tex` | Supplementary Tables 1–4 (placeholders) |
| `supplementary_figures.tex` | Supplementary Figures 1–2 (placeholders) |

## Planned items

2. Complete dataset inventory  
3. Participant/session completeness  
4. BIDS validation results  

**Figures**

1. Detailed BIDS directory structure  
2. Additional quality-control information  

## Compilation options

1. **Separate supplementary PDF (recommended for journal submission):** create a small wrapper `.tex` that `\input`s these files, or paste into the journal’s supplementary template.  
2. **Internal review appendix:** uncomment the appendix block at the end of `main.tex`.

Do not invent values. Cite supplementary items from the main text once content exists (e.g. Supplementary Table~1).
